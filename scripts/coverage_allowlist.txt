# Lines tolerated by `scripts/coverage_gate.sh` despite reporting zero
# execution count. Each entry is `<rel-path>:<line>` followed by a
# `# reason`. Reviewers should push back on any new addition without a
# concrete justification.
#
# Categories present below:
#
# - **tracing-arg**: a field expression inside a `tracing::warn!`/etc.
#   macro. The argument is evaluated lazily by the subscriber. Tests
#   here run with no global subscriber installed (because installing one
#   is process-global and would race with other parallel tests), so the
#   field formatter never fires. The line itself executes; only the
#   closure body inside the macro counts as uncovered.
#
# - **serde-infallible**: `serde_json::to_string(&v).map_err(|e| ...)`
#   error closures. `serde_json::Value` cannot fail to serialize (no
#   custom Serialize impls in scope, no non-string keys), so the
#   closure body is provably unreachable.
#
# - **dead-defensive**: `Err(_)` arms guarded by an upstream invariant
#   that mathematically cannot be violated. Removing them would lose
#   the documentation value of "this branch was considered and ruled
#   out"; keeping them in code costs one allowlist line.
#
# - **platform-conditional**: code that only fires when running as a
#   non-root user, or with `$HOME` unset, or on a non-Linux host. The
#   CI matrix is fixed at `ubuntu-latest` running as root.
#
# - **brace-attribution**: llvm-cov assigns a closing `}` of an
#   `if let Some(_) { ... }` chained off `?` to the closure's region.
#   When the `?` propagates Err, the body never reaches the brace.
#   On the happy path every other line in the function executes.
#
# - **shim-fn-real-io**: a 1-2 line wrapper that constructs real
#   `tokio::io::stdin()` / opens a real WebSocket / spawns a real
#   subprocess. The injectable testable core (`run_io`, `drive_ws_pump`,
#   etc.) is exercised by unit tests; this shim is the part that wires
#   in the real I/O.
#
# - **ws-connect-prelude**: code in `relay::run` between the WebSocket
#   handshake and the `pump_inbound` call (writer task spawn, hello
#   frame send, cleanup). Reachable only with a real WS server; the
#   testable inner loop `pump_inbound` is fully covered.
